# 验证设计

## 对象
先验证 README 中用户真正执行的安装命令；技能包保持 3 个文件，不增加运行时脚本。

## 方案
首次安装先检查目标；已安装则明确停止。升级先将原目录移到 Skills 目录之外的独立备份，再走首次安装。保留个人文件，不合并新旧技能目录。

## 验收
1. 首装得到准确的 3 个技能文件。
2. 重复安装明确提示升级，原目录不变。
3. 升级后只有新版文件，无嵌套目录、旧 CLI。
4. 备份保留完整旧版及个人修改，可恢复。

## 证据
在临时目录导出 v0.1.0 并执行 README 命令。2026-10-13：先复现重复安装变为 6 文件、旧 CLI 残留；修改后 5 项验收通过，按相对路径和 SHA256 核对内容。

## 局限
文件安装验收不能证明 Agent 行为正确，后续另测真实任务与会话恢复。
