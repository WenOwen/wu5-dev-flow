# PRD：Wu5 Dev Flow

## 用户
和 AI 一起开发软件，希望流程简短、进度可检查的开发者。

## 目标
从当前任务开始，完成一个有验证证据的小结果；换会话后仍能继续。

## 为什么
旧版的审批、状态机和过程文件造成阅读与操作负担。这是提出者的真实反馈，尚无其他用户验证。

## 核心能力
1. 按任务选择调研、需求、设计、开发或发布阶段。
2. 按需维护短文档，每份新文档不超过 500 字。
3. 测试、实现、验证、小步提交，并记录下一步。

## 不做
工作流平台、重复审批、自动对外发布、大量过程文件。

## 成功标准
用户能按说明安装；旧版可保留并安全升级；一次任务能留下真实验证与下一步。安装成功不等于行为验证通过。
